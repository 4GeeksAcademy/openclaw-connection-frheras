# Notas de configuración

## VPS
- Tuve poca estabilidad en la conexión con el VPS: se caía constantemente, lo que dificultó la conectividad durante toda la práctica.

## Telegram + Zapier
- Con Zapier tuve problemas desde macOS: el enlace que Telegram generaba al seguir el prompt de Zapier no terminaba de conectar.
- Probé varias veces y también intenté la conexión a través de un túnel, pero el problema persistía en Mac.
- Decisión final: realizar la conexión desde un ordenador con Windows, usando además un enlace de túnel para evitar que fallara.
- Con esa configuración (Windows + túnel) la conexión se estableció correctamente.
